# ZeiGames Source for Hydra Launcher

Download source for Hydra Launcher containing games from ZeiGames.

- Total games: 5,720

## How to use

1. Copy the raw URL to zeigames.json:
   https://raw.githubusercontent.com/therealgofrez/zeigames-hydra-json/main/zeigames.json

2. Open Hydra Launcher.
3. Go to Settings > Download Sources.
4. Add the URL.
